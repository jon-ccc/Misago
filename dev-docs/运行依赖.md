# Misago 运行依赖

## 1. Docker 未安装

Docker 是运行此项目的必要条件，请先安装 Docker Desktop（包含 Docker Engine + Docker Compose v2）：

- 下载地址：
 `https://www.docker.com/products/docker-desktop/`

安装后验证：

```bash
docker --version
docker compose version
```

---

## 2. Node.js 版本过低

当前 Node.js 版本为 `v8.9.1`，Misago 前端需要现代 Node.js 版本（至少 v16+），建议通过 nvm 安装：

```bash
# 安装 nvm
  171  curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.5/install.sh | bash
  172  source  ~/.bashrc
  173  export NVM_NODEJS_ORG_MIRROR=https://npmmirror.com/mirrors/node
  174  nvm install 24.20.0
  175  nvm use 24.20.0

source ~/.zshrc
```

```


node -v   # 应输出 v24.20.0
npm -v    # 应输出 11.19.0

```

```

npm config get registry   # 应输出 https://registry.npmmirror.com/

```

---

## 3. 前端未构建

`frontend/node_modules/` 不存在，需要安装依赖并构建：

```bash
cd frontend
npm install
npm run build    # 生产构建，或 npm run start 用于开发热重载
```

---

## 完整启动流程

按顺序执行以下步骤：

```bash
# 1. 安装 Docker Desktop（手动下载安装）
#    下载地址：https://www.docker.com/products/docker-desktop/

# 2. 安装 Node.js 20+
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install 20
nvm use 20

# 3. 构建前端
cd frontend
npm install
npm run build
cd ..

# 4. 初始化数据库 + 创建 Docker 容器
./dev init

# 5. 启动所有服务
docker compose up
```
