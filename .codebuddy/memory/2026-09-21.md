## Git push 失败排查与修复

- 问题：`git push` 报 `Failed to connect to github.com port 443`，但 `ping github.com` 正常（ICMP 通）
- 原因：网络环境对 GitHub 的 443 端口（HTTPS）做了阻断，ICMP 不受影响
- 排查：无 git/http 代理配置；`curl -v https://github.com` 确认 443 端口超时
- 解决：将 remote 从 HTTPS 改为 SSH 协议（走 22 端口，未被封）
  - `git remote set-url origin git@github.com:jon-ccc/Misago.git`
  - 已有 `~/.ssh/id_rsa` 密钥，SSH 认证为用户 `jon-ccc`
  - `ssh-keyscan` 添加 GitHub host key 到 `~/.ssh/known_hosts`
  - `git push origin main` 成功
